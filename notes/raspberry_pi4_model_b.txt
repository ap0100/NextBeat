KEY SETUP STEPS AND INFO
-------------------------
*no need for virtual environment, once logged into pi, just do cd ~/hr_monitor, all codes are there and every library is installed

for max30102: https://github.com/doug-burrell/max30102.git
for tft gc9a01: write directly to the framebuffer (/dev/fb0):
		-> once logged into pi, do sudo nano /boot/firmware/config.txt
		-> add dtoverlay=gc9a01,width=240,height=240 at the end
		-> make sure dtparam=i2c_arm=on and dtparam=spi=on or similar
		-> in hr_monitor sudo apt-get install python3-pil, sudo apt install python3-smbus python3-numpy (or pip install pillow numpy smbus2 smbus)
		

to run code on the pi, simply write python3 fileanme.py in pi4B@192.168.1.231, in hr_monitor
